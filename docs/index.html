核心特性
为什么选择 VNT APP
专为现代网络场景设计

全平台支持

Android、iOS、Windows、macOS、Linux 一套代码，统一体验，随时随地保持连接。

高性能内核

Rust 编写的核心引擎，低延迟、高吞吐，P2P 直连优先，自动穿越 NAT 障碍。

安全加密

支持 AES-GCM、ChaCha20 等多种加密算法，数据指纹验证，端到端安全保障。

实时监控

流量统计、设备延迟、丢包率、NAT 类型一目了然，网络状态尽在掌握。

智能路由

自动选择最优路径，支持中继回退，端口转发，保证最佳连接质量。

简单配置

图形化界面，配置导入导出，多配置管理，一键连接，无需复杂命令行操作。

其他平台
不止桌面与移动端
在 NAS、路由器和容器环境中继续接入 VNT

飞牛 NAS

面向飞牛 NAS 的 FPK 安装包

提供手动上传安装方式，支持 x86 arm 等多种架构，首次安装后可在应用内填写配置并启动。

FPK 安装包 多架构支持 适合常驻运行
查看仓库 飞牛应用商店手动上传安装

群晖 NAS

面向 DSM 的 SPK 套件包

适合把 VNT 接入群晖设备长期在线使用。支持 DSM6 DSM7 等版本和 x86 arm 等多种架构，需要 root 权限。

SPK 套件包 多架构 NAS 常驻
查看仓库 套件中心手动上传安装

华硕改版梅林

适配改版梅林：Koolshare、SWRT 的离线安装包

适合直接部署到家用路由器侧，让路由器作为稳定的组网入口，省去单独维护终端常驻进程的成本。

Merlin Koolshare SWRT
查看仓库 仅支持软件中心 384 及以上版本

OpenWrt LuCI

给 OpenWrt 增加 VNT 的图形化管理入口

支持在 OpenWrt 编译流程中集成 luci-app-vnt，既能编译 LuCI 管理界面，也能继续编译客户端和服务端程序，适合软路由和定制固件。

LuCI 图形界面 IPK / APK 源码集成
查看仓库 适合固件开发和现有系统集成

Docker

用容器快速部署 CLI 版 VNT 客户端

镜像名为 lmq8267/vnt ，适合 NAS、轻量主机、容器化宿主环境。支持环境变量设置运行无tun模式。

Docker CLI 特权、Host 网络 支持无 TUN
docker run --name vnt-cli --net=host --privileged -d lmq8267/vnt -k <token>
查看Docker 适合快速试跑或无界面常驻部署

SSH 命令行自行部署

适合有 SSH 权限的 Linux、NAS、云主机环境

适合熟悉命令行的用户远程登录设备后自行部署，可按仓库说明选择 CLI 或无 TUN 方案，便于在轻量主机、NAS、旁路机环境中灵活接入。
